Privacy policy

rclone cold-storage is a personal desktop tool. It runs entirely on the user's own computer.

  • It uses Google Drive access only to upload, list, download and delete the files the user chooses, in the user's own Drive.
  • The OAuth token is stored only in the local rclone configuration file on the user's computer.
  • No data is collected, stored, sold or shared with the developer or any third party. There are no servers, analytics or tracking.
  • Access can be revoked at any time at myaccount.google.com/permissions.
